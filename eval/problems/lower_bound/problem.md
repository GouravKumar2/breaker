Lower Bound.

Input: the first line contains n (1 <= n <= 100000). The second line contains n integers a_1 <= a_2 <= ... <= a_n (|a_i| <= 10^9), sorted in non-decreasing order. The third line contains an integer x (|x| <= 10^9).
Output: the smallest 0-based index i such that a_i >= x, or n if no such index exists.

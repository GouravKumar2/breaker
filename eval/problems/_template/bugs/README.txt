Hand-written buggy variants go here, one file each, named  <bug_type>__<short_name>.py  (or .cpp).
bug_type is one of: off_by_one, flip_comparison, wrong_loop_bound, int32_overflow, missing_edge_case, other
Python correct.py also gets AST-mutated variants automatically.
To add a problem: copy this _template folder to eval/problems/<your_name>/ and edit the files.
